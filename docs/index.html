Quick Start

Get GalfitX up and running in minutes

1

Prerequisites

Python 3.11+
GalfitS installation
Astronomical image data (FITS format)
2

Installation

# Clone the repository
git clone https://github.com/pinsongzhao/zps-gx.git
cd zps-gx

# Install dependencies
pip install -r requirements.txt

# Install the package
pip install -e .
3

Configuration

# csst.toml
detect_minarea_cold = 5
detect_minarea_hot = 5
detect_thresh_cold = 1.5
detect_thresh_hot = 2.0
deblend = true
# ... more configuration
4

Run Analysis

from galfitx import core_galfitx

result = core_galfitx(
    image_name="./detection.fits",
    weight_name="./weight.fits",
    # ... configure parameters
)
