Installation Guide

Complete step-by-step instructions for installing GalfitX and its dependencies.

1

Prerequisites

Before installing GalfitX, ensure you have:

  • Python 3.11 or higher
  • GalfitS installed on your system
  • Required astronomical libraries (Astropy, Photutils, etc.)
  • At least 8GB RAM for optimal performance
2

Download GalfitX

Clone the repository from GitHub:

# Clone the repository
git clone https://github.com/pinsongzhao/zps-gx.git
cd zps-gx
3

Install Dependencies

Install all required Python packages:

# Install dependencies
pip install -r requirements.txt

# Install the package in development mode
pip install -e .
4

Verify Installation

Test that everything is working correctly:

# Test the installation
from galfitx import core_galfitx
print("GalfitX imported successfully!")

Data Preparation

Prepare your astronomical images and calibration files for processing.

1

Image Format Requirements

Your astronomical images should be in standard FITS format with:

  • Proper astrometric calibration (WCS keywords)
  • Pixel scale information in the header
  • Magnitude zeropoint information
  • Consistent pixel scales across bands (if doing multi-band)
2

PSF Files

Prepare PSF files for each band:

  • Same pixel scale as science images
  • Normalized to unit total flux
  • Centered on the central pixel
  • Representative of typical seeing in your data
3

Weight Maps

Create weight maps for noise estimation:

  • Each pixel contains inverse variance (1/σ²)
  • Zero for bad pixels or cosmic rays
  • Matches the dimensions of science images

First Analysis

Run your first galaxy analysis pipeline from start to finish.

1

Configure Analysis

Create a configuration file for your analysis:

# config.toml
detect_minarea_cold = 5
detect_minarea_hot = 5
detect_thresh_cold = 1.5
detect_thresh_hot = 2.0
deblend = true
deblend_nthresh_cold = 32
deblend_nthresh_hot = 32
deblend_mincont_cold = 0.005
deblend_mincont_hot = 0.005
pixel_scale = 0.05
sizefac = 8
2

Prepare Input Files

Organize your input files in the correct directory structure:

analysis/
├── data/
│   ├── detection.fits
│   ├── weight.fits
│   ├── science.fits
│   └── psf.fits
├── config.toml
└── analysis.py
3

Run the Analysis

Execute the main pipeline function:

from galfitx import core_galfitx

result = core_galfitx(
    image_name="./data/detection.fits",
    weight_name="./data/weight.fits",
    kernel_name="./data/kernel.txt",
    image_list=["./data/science.fits"],
    outdir_list=["./output/"],
    filter_list=["F814W"],
    label_list=["acs"],
    psf_list=["./data/psf.fits"],
    zero_list=[25.96],
    config="./config.toml"
)
4

Analyze Results

Examine the output files in your output directory:

  • Model fit images
  • Residual images
  • Fitted parameter catalogs
  • Morphological measurements
