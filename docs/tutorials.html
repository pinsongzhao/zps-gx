Getting Started with GalfitX

This tutorial will guide you through the basic installation and first steps with GalfitX.

1 Prerequisites

Before installing GalfitX, ensure you have:

  • Python 3.11 or higher
  • GalfitS installed on your system
  • Astronomical image files (FITS format)
  • Weight maps for your images (optional but recommended)

2 Installation

First, clone the repository and install dependencies:

# Clone the repository
git clone https://github.com/pinsongzhao/zps-gx.git
cd zps-gx

# Install dependencies
pip install -r requirements.txt

# Install the package
pip install -e .

3 Prepare Input Files

You'll need several input files for the pipeline:

  • Detection image (for source detection)
  • Weight image (for noise estimation)
  • Convolution kernel file
  • Multiband science images
  • PSF files for each band (if available)
  • Configuration file (.toml)

4 Create Configuration File

Create a configuration file named csst.toml:

detect_minarea_cold = 5
detect_minarea_hot = 5
detect_thresh_cold = 1.5
detect_thresh_hot = 2.0
deblend = true
deblend_nthresh_cold = 32
deblend_nthresh_hot = 32
deblend_mincont_cold = 0.005
deblend_mincont_hot = 0.005
clean = true
back_type = "AUTO"
back_value = 0.0
back_size_cold = 64
back_size_hot = 64
back_filtersize = 3
BACKGROUND = "WEIGHT"
scale_factor = 1.0
pixel_scale = 0.05
sizefac = 8
scale = 1.0
offset = 0
limgal = -1
b = 0.3
setup = "setup_file.conf"

Basic Galaxy Analysis

This tutorial covers how to run a basic galaxy decomposition analysis.

1 Prepare Your Data

Organize your data files:

your_analysis/
├── detection_image.fits
├── weight_image.fits
├── kernel.txt
├── band1_image.fits
├── band2_image.fits
├── psf_band1.fits
├── psf_band2.fits
└── config.toml

2 Write Analysis Script

Create a Python script to run the analysis:

from galfitx import core_galfitx

result = core_galfitx(
    image_name="./detection_image.fits",
    weight_name="./weight_image.fits",
    kernel_name="./kernel.txt",
    image_list=["./band1_image.fits", "./band2_image.fits"],
    outdir_list=["./output/band1/", "./output/band2/"],
    filter_list=["F475W", "F814W"],
    label_list=["band1", "band2"],
    psf_list=["./psf_band1.fits", "./psf_band2.fits"],
    zero_list=[25.0, 25.0],
    config="./config.toml"
)

3 Run the Analysis

Execute your script to start the analysis:

python your_analysis_script.py

4 Examine Results

After completion, examine the results in the output directories. The pipeline generates:

  • Postage stamps of detected sources
  • Masks for neighboring objects
  • Best-fit model images
  • Residual images
  • Fitted parameter files

Advanced Usage Patterns

This section covers more sophisticated usage of GalfitX.

1 Custom Component Models

To add custom component models, modify the setup files generated by create_setup_gs.py. You can add additional components such as bars, rings, or other structures beyond the basic Sersic profiles.

2 Multi-epoch Analysis

For multi-epoch data, create separate analysis runs or modify the pipeline to handle temporal variations. You can fix certain parameters across epochs while allowing others to vary.

3 Batch Processing

For large datasets, consider implementing batch processing:

import os
from galfitx import core_galfitx

def process_field(field_id, image_paths, weight_paths):
    """Process a single field with multiple bands"""
    for i, (img, wgt) in enumerate(zip(image_paths, weight_paths)):
        result = core_galfitx(
            image_name=img,
            weight_name=wgt,
            # ... other parameters
        )

# Process multiple fields in sequence
fields = load_field_list()
for field in fields:
    process_field(field.id, field.images, field.weights)

4 Custom Quality Control

Implement custom quality control routines to evaluate the goodness of fit:

from astropy.io import fits
import numpy as np

def evaluate_fit_quality(model_file, residual_file):
    """Evaluate the quality of the fitted model"""
    with fits.open(model_file) as model_hdu, fits.open(residual_file) as res_hdu:
        model = model_hdu[0].data
        residual = res_hdu[0].data

        # Calculate reduced chi-square
        chi_sq = np.sum((residual / np.sqrt(np.abs(model)))**2)
        dof = residual.size - n_fitted_params  # degrees of freedom
        reduced_chi_sq = chi_sq / dof

        return reduced_chi_sq
