# GalfitX Documentation Website

Welcome to the GalfitX documentation website! This site provides comprehensive documentation for the GalfitX astronomical image processing pipeline.

## Overview

GalfitX is a sophisticated astronomical image processing pipeline that provides automated source detection, image decomposition, and photometry measurements across multiple wavelengths. The pipeline integrates the robust GalfitS modeling software with custom preprocessing and postprocessing utilities for comprehensive galaxy analysis.

## Features

- **Multi-wavelength Analysis**: Supports processing of multi-band imaging data
- **Automated Pipeline**: Fully automated source detection and fitting procedures
- **Astronomical Focus**: Specifically designed for galaxy morphology and photometric analysis
- **Modular Architecture**: Flexible, component-based design allowing customization
