Galaxy Morphology Analysis

Understanding the shapes, structures, and evolution of galaxies

Early-Type Galaxy Decomposition

Advanced 45 min

Analyze a massive elliptical galaxy using bulge+disk decomposition models. This example demonstrates how to fit complex light profiles with GalfitX.

Configuration Setup
# Early-type galaxy analysis
config = {
    "detect_minarea_cold": 25,
    "detect_thresh_cold": 2.0,
    "deblend": False,  # No deblending for isolated galaxies
    "sizefac": 12,  # Larger stamps for extended galaxies
    "setup_components": ["sersic"]  # Just a single Sersic component
}
Expected Results
  • Sersic index (n) characterizing the light profile shape
  • Effective radius (reff) in arcseconds
  • Total magnitude and concentration index
  • Axis ratio and position angle

JWST NIRCam Deep Field Analysis

Advanced 120 min

Complete analysis of a deep field observed with JWST NIRCam across 6 bands (F115W to F444W) as demonstrated in the gxdemo.py script.

Multi-band Configuration
# Multi-band NIRCam analysis
sciname_list = ['F444W_sci.fits', 'F356W_sci.fits', 'F277W_sci.fits',
                'F200W_sci.fits', 'F150W_sci.fits', 'F115W_sci.fits']

label_list = ['F444W', 'F356W', 'F277W', 'F200W', 'F150W', 'F115W']
filter_list = ['nircam_f444w', 'nircam_f356w', 'nircam_f277w',
               'nircam_f200w', 'nircam_f150w', 'nircam_f115w']

# PSF files and zeropoints
psf_list = ['./psfs/f444w_psf.fits', './psfs/f356w_psf.fits',
            './psfs/f277w_psf.fits', './psfs/f200w_psf.fits',
            './psfs/f150w_psf.fits', './psfs/f115w_psf.fits']

zero_list = [27.462, 27.462, 27.462, 28.967, 28.967, 28.967]
Workflow Steps
  1. HDR source detection with dual-mode thresholding
  2. Postage stamp creation for all sources and bands
  3. Neighboring object masking to minimize contamination
  4. Joint GalfitS modeling across all bands
  5. Photometric redshift derivation with EAZY
  6. SED fitting and physical property determination

Gravitational Lensing Analysis

Advanced 90 min

Analyze lensed galaxies and Einstein rings using specialized model components and constraints.

Lensing Model Setup
# Gravitational lensing model with external shear
lens_config = {
    "components": ["lensed_sersic", "shear_field"],
    "constraints": {
        "positions_locked": True,  # Lens position fixed
        "multiplicative_shear": True,  # Apply shear distortions
        "flexible_profiles": True  # Allow variable Sersic indices
    },
    "sampling_options": {
        "oversample_factor": 4,  # Higher resolution sampling
        "psf_convolution": True  # Proper PSF convolution
    }
}

Star Formation History Reconstruction

Advanced 180 min

Combine morphological analysis with SED fitting to reconstruct star formation histories.

Integrated Analysis Pipeline
from galfitx.model_isoflux import PhotometryPipeline
from galfitx.eazy_utils import run_eazy

# Step 1: Morphological analysis
iso_config = PhotometryConfig(
    image_list=sciname_list,
    galaxy_catalog=catalog_name,
    psf_file=psf_file,
    label_list=label_list,
    filter_labels=filter_list,
    # ... other parameters
)

iso_pipeline = PhotometryPipeline(iso_config)
bg_params = iso_pipeline.step2_fit_background_noise()

# Step 2: SED fitting with EAZY
for galaxy_id in selected_galaxies:
    # Derive photometry from morphological fits
    photometry = extract_photometry(galaxy_id, iso_pipeline)

    # Run EAZY for SED fitting
    zphot_result = run_eazy(photometry, config_file)

    # Combine morphological and SED results
    combined_results = integrate_morphology_sed(morph_result, zphot_result)

GalfitX Demo Deep Dive

Exploring the comprehensive gxdemo.py workflow in detail

Overview of gxdemo.py

The gxdemo.py script provides a complete end-to-end demonstration of GalfitX capabilities, implementing a sophisticated multi-wavelength analysis pipeline:

Advanced Source Detection

HDR (High Dynamic Range) detection with dual-mode thresholding to simultaneously detect faint extended sources and bright compact objects

Multi-band Processing

Simultaneous analysis of 6 NIRCam bands from F115W to F444W with consistent calibration

Object Grouping

Automatic grouping of related objects that should be fitted simultaneously to account for blending

Photometric Redshifts

Integration with EAZY for SED fitting and photometric redshift determination

Joint Image+SED Fitting

Combining morphological and spectral information for improved physical parameter estimation
