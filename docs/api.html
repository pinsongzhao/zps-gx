GalfitX API Reference

Core Module: galfitx_main.py

core_galfitx

Main pipeline function that orchestrates the entire astronomical image processing workflow.

core_galfitx(
    image_name: str = "/path/to/image",
    weight_name: str = "/path/to/weightimage",
    kernel_name: str = "/path/to/kernel",
    image_list: List[str] = ["/path/to/image"],
    outdir_list: List[str] = [],
    filter_list: List[str] = [],
    label_list: List[str] = [],
    psf_list: List[str] = [],
    zero_list: List[float] = [],
    config: str = "./csst.toml",
) -> int

Parameters

Parameter Type Description
image_name str Path to detection image
weight_name str Path to weight image
kernel_name str Path to convolution kernel file
image_list List[str] Paths to multi-band science images
outdir_list List[str] Paths to store multi-band postage stamps
filter_list List[str] Filter identifiers used for GalfitS
label_list List[str] Labels for each filter
psf_list List[str] Paths to multi-band input PSF images
zero_list List[float] Multi-band magnitude zeropoints
config str Path to config file

Returns

int: Status code indicating success (1) or failure (0)

Description

The core_galfitx function implements a complete astronomical image processing pipeline. It performs source detection using SExtractor-based algorithms, extracts postage stamps around detected sources, generates masks for neighboring objects, estimates local sky backgrounds, and runs GalfitS to decompose galaxy morphologies.

Description

Implements an advanced source detection algorithm with dual-mode processing capabilities. Uses configurable detection thresholds and deblending parameters to handle complex astronomical scenes.

SExtractor_dualmode

Dual-mode source detection for simultaneous identification of faint and bright objects.

Description

Implements dual-mode detection algorithms that simultaneously apply different threshold settings to detect both faint extended objects and bright compact sources.

Setup Generation: create_setup_gs.py

prepare_galfits

Generates GalfitS setup files for morphological fitting.

prepare_galfits(
    image_stamp_list,
    catalog_name,
    output_name,
    corner,
    mask_files,
    stamp_file,
    psf_files,
    sky_files,
    zero_points,
    labels,
    filters,
    n_images,
    objects=None,
    setup=None,
    sky0=True,
)

Description

Creates configuration files for GalfitS with properly initialized parameters for each source in the catalog. Handles multi-band setup generation and PSF preparation.

process_psf

Processes and prepares PSF files for multi-band fitting.

Description

Handles the preparation of PSF files for each band, including normalization and resampling to match the observed images.

Utility Modules

postage_stamp.py

Functions for extracting and manipulating postage stamps:

  • create_stamp_file: Creates file with stamp coordinates
  • cut_stamps: Extracts stamps from full images

mask.py

Functions for creating object masks:

  • create_mask: Generates masks for neighboring objects
  • prepare_galfitm: Prepares masks for GalfitS

sky_calculation.py

Functions for background estimation:

  • getsky: Estimates local sky background
  • create_skymap: Creates sky background maps

read_setup.py

Functions for reading and parsing configuration files:

  • read_setup: Reads setup configuration files
  • set_trailing_slash: Ensures directory paths have trailing slashes
