API Reference

Comprehensive documentation for all GalfitX modules and functions

Core Module: galfitx_main.py

Main pipeline module containing the core functionality

core_galfitx

core_galfitx( image_name: str = "/path/to/image", weight_name: str = "/path/to/weightimage", kernel_name: str = "/path/to/kernel", image_list: List[str] = ["/path/to/image"], outdir_list: List[str] = [], filter_list: List[str] = [], label_list: List[str] = [], psf_list: List[str] = [], zero_list: List[float] = [], config: str = "./csst.toml", ) -> int

The main pipeline function that orchestrates the entire astronomical image processing workflow. It performs source detection, generates postage stamps, creates masks for neighboring objects, estimates local sky backgrounds, and runs GalfitS for morphological decomposition.

Parameters
image_name
str
Path to detection image used for source finding
weight_name
str
Path to weight image for noise estimation
kernel_name
str
Path to convolution kernel file
image_list
List[str]
Paths to multi-band science images
outdir_list
List[str]
Paths to store multi-band postage stamps
filter_list
List[str]
Filter identifiers used for GalfitS
label_list
List[str]
Labels for each filter
psf_list
List[str]
Paths to multi-band input PSF images
zero_list
List[float]
Multi-band magnitude zeropoints
config
str
Path to configuration file
Returns
int
Status code indicating success (1) or failure (0)

Source Detection: source_detection.py

Advanced source detection algorithms with HDR capabilities

SExtractor_HDR

SExtractor_HDR( image, kernel, detect_minarea, detect_thresh, deblend, deblend_nthresh, deblend_mincont, clean, back_type, back_value, back_size, back_filtersize, weight_type, scale_factor, pixel_scale, mag_zeropoint, verbose=True, )

High Dynamic Range source detection algorithm with adaptive thresholding. Implements dual-mode processing to simultaneously detect both faint extended sources and bright compact objects.

Parameters
image
str or HDU
Input image for source detection
kernel
tuple
Detection kernel for convolution
detect_minarea
tuple
Minimum detection area for cold/hot modes
detect_thresh
tuple
Detection thresholds for cold/hot modes
deblend
tuple
Enable deblending for cold/hot modes

SExtractor_dualmode

Dual-mode source detection for simultaneous identification of faint and bright objects. Optimized for complex astronomical scenes with varying surface brightness.

Setup Generation: create_setup_gs.py

Module for generating GalfitS configuration files

prepare_galfits

prepare_galfits( image_stamp_list, catalog_name, output_name, corner, mask_files, stamp_file, psf_files, sky_files, zero_points, labels, filters, n_images, objects=None, setup=None, sky0=True, )

Generates GalfitS setup files for morphological fitting. Creates configuration files with properly initialized parameters for each source in the catalog and handles multi-band setup generation.

process_psf

Processes and prepares PSF files for multi-band fitting. Handles normalization and resampling to match observed images.
